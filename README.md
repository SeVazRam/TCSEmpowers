# Python para el Análisis de Datos

**Flujo esencial de trabajo para empezar**

## Descripción

Este repositorio contiene material introductorio para aprender los fundamentos del análisis de datos con Python, utilizando Jupyter Notebook y la librería Pandas.

El objetivo es comprender las etapas esenciales de un flujo de trabajo de análisis de datos, desde la carga e inspección de un conjunto de datos hasta su preparación y la identificación de insights que permitan obtener conclusiones útiles.

## Contenido

El repositorio incluye los siguientes recursos:

- **Jupyter Notebook:** ejemplos prácticos, código y explicaciones paso a paso.
- **Presentación PowerPoint:** resumen visual de los conceptos principales y del flujo de trabajo.
- ** Material GoogleColab** Los materiales de google colab estan en el siguiente link

### Temas abordados

1. Apertura de notebooks e importación de librerías.
2. Variables y tipos de datos.
3. Creación de funciones.
4. Carga de archivos CSV.
5. Inspección y exploración de datos.
6. Agrupaciones y resúmenes estadísticos.
7. Tablas dinámicas (*Pivot Tables*).
8. Transformación de datos con `map()` y `apply()`.
9. Combinación de DataFrames con `merge()` y `concat()`.
10. Limpieza y preparación de datos.
11. Identificación de insights para apoyar la toma de decisiones.

##  Tecnologías utilizadas

- Python
- Jupyter Notebook
- Pandas

##  Cómo utilizar este material

1. Descarga o clona este repositorio.
2. Abre el archivo `.ipynb` en Jupyter Notebook, JupyterLab o Google Colab.
3. Ejecuta las celdas en orden para seguir los ejemplos.
4. Revisa la presentación PowerPoint para reforzar los conceptos.
5. Experimenta con tus propios conjuntos de datos en formato CSV.

## 💻 Instalación

Si necesitas instalar Pandas, ejecuta el siguiente comando:

```bash
pip install pandas
```

Para iniciar Jupyter Notebook, puedes utilizar:

```bash
pip install notebook
jupyter notebook
```

## Objetivo de aprendizaje

Al finalizar este material, podrás reconocer y aplicar operaciones básicas de Pandas para cargar, explorar, transformar y resumir datos, estableciendo una base para desarrollar proyectos de análisis exploratorio de datos (*Exploratory Data Analysis — EDA*).
